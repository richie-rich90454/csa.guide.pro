## Contributing to this project

Anybody can contribute to this project. Please write to kirakbit@gmail.com that you want to collaborate with us on this project, and we will reply back to you as soon as we can, so you can start contributing on this project.

### What we need most

This guide now covers **both** the legacy ten-unit curriculum and the new four-unit curriculum. Contributions are especially welcome for:

- More trash code examples (with a matching `**Why It's Trash**` explanation - every trash example needs its counterpart).
- Practice questions with answers for any unit that is light on them.
- New-curriculum topics: text files and data sets, ethics of data collection, binary search, merge sort, and recursive searching/sorting.
- Fixes to code that does not actually compile. Trash code is fine; broken code is just broken.

### House rules

- Keep the voice: rigorous Java wrapped in trash-code satire. `TOP TIP`, `Trash Code Example`, `Why It's Trash`, `Common Errors`, and `Practice Questions` are our house callouts.
- Java stays canonical. Pseudocode and Python asides are allowed, but they are guests in this house.
- Plain Markdown with relative links, no new dependencies.
- Link to both curricula where relevant: [new units](README.md) and [legacy units](README.md).
